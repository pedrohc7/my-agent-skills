# Skill: Criar Copy de Anúncio para Facebook Ads

Quando invocado com `/facebook-ads-copy`, siga este fluxo para gerar textos de anúncio otimizados para engajamento no Facebook e Instagram.

## 1. Coleta de contexto

Pergunte ao usuário:
- Qual é o produto, serviço ou página que será promovido?
- Quem é o público-alvo? (ex: mulheres 25-40, mães de primeira viagem, empreendedores, etc.)
- Qual é o objetivo do anúncio? (curtidas na página, engajamento em publicação, comentários, compartilhamentos, seguidores)
- Qual é o tom de voz desejado? (divertido, profissional, urgente, emocional, inspirador)
- Tem alguma oferta, promoção ou diferencional para destacar?

## 2. Gerar 3 variações de copy

Gere **3 variações completas**, cada uma com abordagem diferente (ex: curiosidade, prova social, pergunta direta):

### Estrutura de cada variação:

**Texto Principal (Primary Text)** — ideal até 125 caracteres, máximo 500
> Primeira linha deve ser o gancho (hook) que para o scroll

**Headline** — até 40 caracteres
> Resumo do valor ou benefício principal

**Descrição** (exibida abaixo da headline) — até 30 caracteres
> Complemento da headline ou CTA reforçado

**CTA sugerido:**
- Curtir Página
- Saiba Mais
- Enviar Mensagem
- Baixar
- Inscrever-se
- Entrar em Contato

## 3. Gatilhos de engajamento a aplicar

Use pelo menos um gatilho em cada variação:
- **Pergunta direta** — convida o usuário a responder nos comentários
- **Curiosidade** — informação incompleta que gera clique ("O que 87% das pessoas não sabem sobre...")
- **Prova social** — número, depoimento ou resultado real ("Mais de 10.000 pessoas já...")
- **Urgência ou escassez** — prazo, vagas limitadas, estoque
- **Identificação** — "Se você é [persona], esse post é pra você"
- **Emoji estratégico** — use 1 a 3 emojis no início ou fim para destacar visualmente

## 4. Recomendação para A/B Test

Após as 3 variações, indique:
- Qual variação testar **primeiro** e por quê
- Qual métrica observar para declarar o vencedor (CTR, Custo por Engajamento, Comentários)
- Após quantos dias ou R$ gastos tomar decisão (regra geral: mínimo R$ 30 ou 3 dias)

## 5. Boas práticas sempre aplicadas

- Primeira linha do texto principal precisa prender a atenção sem precisar clicar em "ver mais"
- Evite linguagem genérica ("Confira nosso produto incrível") — seja específico
- Adapte o tom para o feed (mais elaborado) vs. stories (mais direto e visual)
- Não use clickbait — o Meta penaliza anúncios com linguagem enganosa
- Mantenha consistência entre copy e criativo (imagem/vídeo)
